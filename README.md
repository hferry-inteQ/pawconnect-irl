# Paw Connect IRL

Real-world dog events, adoption drives, dog parks, city guides, pet deals, and product reviews — powered by Paw Connect by inteQ.

## Tech Stack
- Vite + React + TypeScript
- Tailwind CSS
- Supabase (Postgres, Edge Functions, RLS)

## Features
- Dog events across 5 cities (Austin, Dallas, Fort Worth, Chicago, New Orleans)
- Adoption & fostering events
- Dog parks & dog-friendly venues
- City guides
- Online pet deals
- Product reviews (auto feeders, robot litter boxes)
- Paw Connect member benefits CTA
- Write Your Landlord postcard campaign
